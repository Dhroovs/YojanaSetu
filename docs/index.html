Five bounded assistance capabilities.

Discover → Match with evidence → Create a private case → Review documents → Follow up → Escalate to a human → Book doorstep help → Assign a verified worker → Review completion → Track updates

Citizen and field worker

Individual sign-in, private cases and files, source citations, reminders, appointment acceptance, check-in, performed-service notes and feedback.

Coordinator and administrator

Owned review queues, referrals, availability/conflict checks, confirmed assignments, human outcome review, internal worker verification and safe user operations.

The agents assist; humans approve sensitive actions. Document checks are not legal authentication. Internal worker review is not government certification. No Aadhaar verification or automatic government submission is claimed.

Verified scope and honest boundaries

Local demo works. Public backend release is gated.

Verified locally

  • Mongo persistence, private uploads and local ONNX/Chroma retrieval.
  • All five assistance capabilities and multi-role visit lifecycle.
  • Durable in-app reminders and role/object authorization.
  • Production frontend build, lint and automated regressions.
  • Major Hindi/Telugu UI paths and voice text fallback.

Explicit limitations

  • Unresolved Chroma dependency advisories block public backend release.
  • No live LLM call, native microphone/playback or paid messaging is claimed.
  • Hindi/Telugu translations are draft; multilingual free-text RAG is not certified.
  • Only three schemes/four partial official sources; eligibility can remain unknown.
  • No reviewed no-card free host meets the full persistent-storage and worker needs.
